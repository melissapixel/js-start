Задание 2.
  На странице есть модальное окно (оверлей + контент по центру). 
  
  Есть кнопка «Открыть модалку». 
  
  При клике модалка появляется, фон затемняется, скролл страницы блокируется. 
  
  Закрыть можно тремя способами: клик по крестику, нажатие клавиши Escape. При закрытии скролл разблокируется.
